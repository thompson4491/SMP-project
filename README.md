# Student Management Program

The **Student Management Program (SMP)** is a Python-based command-line application designed to manage student records. It allows users to add, view, search, update, and delete student information through a simple interactive menu.

The program demonstrates fundamental Python programming concepts including **object-oriented programming, functions, lists, loops, conditional statements, user input validation, and file handling**. Student records are stored in JSON format within a local text file, allowing information to be saved and loaded between program sessions.

## Features

- Add new student records
- View all registered students
- Search for students by ID or name
- Update existing student information
- Delete student records
- Prevent duplicate student IDs
- Validate age input
- Save student records to a local file
- Load previously saved records when the program starts
- Automatically save records when the program exits

## Technologies Used

- **Python 3**
- **JSON**
- **Command Line Interface (CLI)**

## Student Information

Each student record contains:

- Student ID
- Name
- Age
- Grade
